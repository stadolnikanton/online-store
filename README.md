# Online Store Project

Учебный проект интернет-магазина. Реализован каталог товаров, корзина и система пользователей.

## Стек технологий
* Python
* Управление зависимостями: uv
* БД: SQLite/PostgreSQL (через SQLAlchemy)
* Миграции: Alembic

## Как запустить

1. Скачайте репозиторий.
2. Установите библиотеки:
   uv sync

3. Обновите базу данных:
   alembic upgrade head

4. Запуск:
   python main.py
